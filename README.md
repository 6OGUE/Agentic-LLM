# How to Run

1. Create a python virtual environment inside the backend directory
2. Activate the python virtual environment, and install the "requirements.txt"
3. Create a .env file in the backend and populate it with GOOGLE_API_KEY= <your_api_key>
4. Start the backend server using the command "uvicorn agentapi:app"
5. Open a terminal in the frontend directory
6. Run npm install
7. Run npm run dev
8. Follow the url displayed in the terminal
