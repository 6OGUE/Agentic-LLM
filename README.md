# How to Run

1. Create a python virtual environment inside the backend directory
2. Activate the virtual environment and install dependencies with `pip install -r requirements.txt`
3. From the backend directory, start the server with `uvicorn agentapi:app`
4. Open a terminal in the frontend directory, run `npm install`, then run `npm run dev`
5. Follow the URL displayed in the terminal
6. Configure `GOOGLE API KEY` in the app's LLM settings.
